Cómo usarlo

  1. Escribí la escena y tocá Copiar descripción.
  2. Abrí el generador IA y pegá la descripción.
  3. Para foto a video, seleccioná el modo de imagen inicial, si está disponible, y cargá la foto directamente en el motor.
  4. Generá el clip, esperá la cola y descargalo desde el generador.

No se requiere una clave API dentro de esta web. Los servicios gratuitos no garantizan generaciones ilimitadas ni disponibilidad permanente.
